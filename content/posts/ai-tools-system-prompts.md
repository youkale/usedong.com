今天发现了一个神奇的 GitHub 仓库 🎉

## 这是什么？

[system-prompts-and-models-of-ai-tools](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools) - 一个收集各种 AI 编码工具系统提示词的开源项目。

**数据**：
- ⭐ 90.1k stars
- 🍴 24.5k forks
- 📜 20,000+ 行提示词
- 🔓 GPL-3.0 开源

## 包含哪些工具？

**主流 AI 编码工具**：
- Cursor
- v0
- Windsurf
- Devin AI
- Replit
- Claude Code
- GitHub Copilot

**其他 30+ 工具**：
Lovable, Manus, Perplexity, Notion AI, Warp.dev, Xcode, VSCode Agent...

## 为什么有用？

1. **学习 AI 提示词设计** - 看看大厂怎么写系统提示词
2. **理解工具原理** - 了解 AI 编码工具的内部逻辑
3. **优化自己的提示词** - 参考和借鉴最佳实践
4. **开发类似工具** - 开源项目都在这里

## 我的发现

翻了几个文件，发现：

- Cursor 的提示词超详细，难怪补全那么准
- v0 的设计模式提示词很有参考价值
- Windsurf 的 Agent 提示词写得很专业

这些都是**真实的生产环境提示词**，不是网上的教程那种。

## 注意事项
